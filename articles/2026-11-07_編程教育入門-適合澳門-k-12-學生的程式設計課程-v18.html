編程教育入門：適合澳門 K-12 學生的程式設計課程

2026-11-07 · 8 分鐘閱讀 · 澳門教育資源中心

適合澳門 K-12 學生的編程教育入門課程，通常建議按「建立興趣—掌握基本概念—完成互動作品—進行專題探究」的順序展開：小學生可從 Scratch 圖形化編程及 micro:bit 硬件項目開始，中學生再逐步學習 Python、資料處理與演算法。課程選擇應配合年齡、程度及STEAM 學習目標，而非只追求學會某一項工具。澳門教育資源中心整理以下入門框架，協助家長與老師評估課程是否真正包含動手實作、問題分析及作品分享。

一、認識 K-12 編程教育的學習階段

K-12 涵蓋幼稚園至中學教育。不同學段的學生在閱讀能力、數學基礎、抽象思考及自訂律方面差異很大，因此編程入門不應只以年齡劃分，也應考慮學生是否接觸過電腦、能否理解因果關係，以及對遊戲、動畫或機械裝置是否有興趣。

  • 幼小階段：以操作電腦、序列、事件、循環及簡單條件為主，重點是建立「指令—結果」的思維。
  • 小學階段：透過 Scratch 製作動畫、遊戲與互動故事，並可接觸 micro:bit 感測器及簡單電子作品。
  • 初中階段：開始使用 Python 等文字型語言，學習變數、函式、演算法、資料結構及除錯方法。
  • 高中階段：可加入演算法分析、網頁開發、數據可視化、人工智慧應用或硬件控制，培養系統化思考與專題研究能力。

澳門教育資源中心建議，幼小生宜以圖形化工具降低門檻，而中學生則可在需要時由文字型語言提升編程能力。編程語言只是工具，核心仍是拆解問題、測試方案及修正錯誤。

二、澳門學生常見的入門工具與課程方向

1. Scratch：建立編程思維

Scratch 以積木式操作降低語法門檻，學生可製作遊戲、動畫及互動作品。入門課程應要求學生設計明確目標、處理輸入與輸出、加入條件判斷，並用作品解釋自己的解題過程，而不只是在課堂上完成指定步驟。

2. Python：銜接文字型編程

Python 語法相對清晰，適合用作中學生的第一門文字型語言。課程可由輸入與輸出、變數及條件開始，逐步加入列表、字典、函式、檔案操作與基本演算法。合適的學習成果包括文字遊戲、記錄整理工具、猜數遊戲或簡單資料分析報告。

3. micro:bit：由軟件走向硬件

micro:bit 提供按鈕、LED、感測器及擴充接口，可讓學生製作電子遊戲、計步器、溫度顯示器或環境監測裝置。這類課程特別適合結合STEAM：先以圖形化或 Python 編程，再測試感測器數據，最後記錄結果並改善裝置。

三、選擇課程時應檢查的六項重點

  1. 是否循序漸進：每個階段是否建立在前一項知識之上，而非短期堆砌語法。
  2. 是否有實作比例：課堂應包含獨立設計、測試及展示作品，讓學生真正運用所學。
  3. 是否教授除錯方法：引導學生閱讀錯誤訊息、分段檢查及尋找原因，比只示範正確答案更重要。
  4. 是否涵蓋電腦科學概念：除工具操作外，也應介紹序列、抽象化、演算法、資料及泛化等概念。
  5. 是否符合學生程度：可先進行小組任務或無壓力體驗，再根據表現調整課程。
  6. 是否有安全規範：涉及帳戶、密碼、個人資料及上載作品時，應說明私隱、網絡安全與適當分享原則。

優質課程的評量不宜只看「有沒有完成程式」。家長可觀察學生能否說明作品功能、遇到問題時採取甚麼方法，以及修改後能否比較前後效果。澳門教育資源中心也建議將編程成果與語文、數學、科學及藝術結合，例如以數據製作圖表，或以故事及角色設計演算法遊戲。

四、家長可採用的入門學習路徑

第一步可讓學生接觸 Scratch，製作一個包含事件、條件及計分功能的短遊戲；第二步轉用 Python 重寫其中一項功能，讓學生比較文字型語言與積木式編程；第三步可選 micro:bit 製作感測器作品，處理真實環境中的輸入；第四步則完成一個結合多項知識的個人專題，並向家人或同學展示。

  • 每週保留固定但適量的實作時間，避免只參加講解、沒有動手環節。
  • 鼓勵學生先畫流程圖或寫下步驟，再開始編碼。
  • 把錯誤視為修正程式的資料，不要立即代為完成。
  • 保留學習歷程、作品版本及反思紀錄，方便評估能力成長。
  • 選購設備前先確認課程是否需要特定平台、瀏覽器及額外感測器配件。

總括而言，適合澳門 K-12 學生的程式設計課程，應同時提供清晰分級、動手實作、除錯訓練及跨學科應用。短期內未必需要掌握大量語法，但應逐步建立計算思維、創造力與獨立解題能力；家長亦可參與作品討論，減少只關注考級或完成速度的傾向。

常見問題

Q: 澳門學生由幾歲開始學編程較合適？
A: 沒有統一起點。可先讓幼小生接觸序列、事件與循環，小學可使用 Scratch 或 micro:bit，中學再學習 Python；重點是能力與興趣。
Q: Scratch 與 Python 哪一種更适合入門？
A: Scratch 適合建立流程及條件概念，Python 適合進一步學習文字語法、演算法與資料處理。一般可先學 Scratch，再按程度轉向 Python。
Q: 判斷編程課程是否優質有哪些方法？
A: 留意課程是否循序漸進、包含獨立實作、除錯訓練、跨學科應用及作品展示，並確認設備要求與網絡私隱指引是否清晰。
